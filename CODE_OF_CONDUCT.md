# Code of Conduct

This project adopts the Contributor Covenant, version 2.1, by reference:
https://www.contributor-covenant.org/version/2/1/code_of_conduct/

All contributors and participants in project spaces are expected to follow it.

## Enforcement

Report conduct concerns to the repository maintainers privately, either
through the repository's Security tab or by opening a private advisory on the
repository. Do not use public issues for conduct reports.

The maintainers will review each report, keep the reporter's identity
confidential, and apply the enforcement guidelines set out in the Contributor
Covenant.
